# 🍽️ GastroFlow Web

Frontend de GastroFlow, una plataforma de gestión gastronómica diseñada para ofrecer una experiencia moderna, intuitiva y responsive tanto para clientes como para restaurantes.

La aplicación permite explorar restaurantes, visualizar menús digitales, realizar reservas online y gestionar órdenes en tiempo real mediante una interfaz enfocada en la usabilidad y simplicidad visual.

El proyecto fue desarrollado utilizando Next.js y una arquitectura basada en componentes reutilizables, priorizando la experiencia de usuario, la escalabilidad y el rendimiento de la aplicación.

---

# 🚀 Funcionalidades

## 👤 Clientes

- Exploración de restaurantes adheridos
- Visualización de menús digitales
- Reservas online
- Gestión de órdenes
- Persistencia de sesión mediante JWT
- Interfaz responsive para dispositivos móviles

---

## 🍽️ Restaurantes

- Gestión de mesas y reservas
- Visualización de comandas en tiempo real
- Flujo de órdenes y cocina
- Paneles administrativos
- Gestión de productos y categorías
- Administración de empleados

---

# ✨ Experiencia de Usuario

La aplicación fue diseñada con una interfaz minimalista, moderna e intuitiva, enfocada en facilitar la navegación y mejorar la experiencia del usuario.

## Características UX/UI

- Diseño responsive mobile-first
- Loading states
- Alertas interactivas con SweetAlert2
- Uso de modales dinámicos
- Navegación fluida e intuitiva
- Actualizaciones en tiempo real
- Validaciones de formularios
- Manejo global del estado de autenticación

---

# ⚙️ Arquitectura Frontend

El frontend consume la API de GastroFlow mediante Axios y Context API para el manejo global del estado y autenticación.

## Buenas prácticas implementadas

- Arquitectura basada en componentes reutilizables
- Separación de responsabilidades
- Manejo global de estado con Context API
- Consumo centralizado de APIs
- Persistencia de sesión
- Manejo de estados de carga y errores
- Responsive Design
- Validaciones de formularios
